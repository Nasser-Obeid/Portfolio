# Nasser Obeid — Portfolio

Personal portfolio website for **Nasser Obeid**, an AI & Automation Engineer based in Amman, Jordan.

## Live Site

[https://nasser-obeid.github.io/Portfolio/](https://nasser-obeid.github.io/Portfolio/)

## Overview

A single-page portfolio built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies. Features smooth scrolling, scroll-reveal animations, responsive layout, and a contact form.

## Sections

- **About** — Introduction, profile photo, and CV download
- **Collaborators** — Auto-scrolling carousel of partner logos
- **Background** — Professional summary
- **Experience** — Work history with role details
- **Projects** — Highlighted technical projects
- **Skills** — Grouped skill tags (RPA, Programming, MLOps, AI/ML, Data Tools)
- **More** — Education, certificates, and languages
- **Contact** — Email form, phone, LinkedIn, and CV download

## Tech Stack

- HTML5 / CSS3 / Vanilla JS
- [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) via Google Fonts
- No external libraries or frameworks

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/portfolio.git
   ```
2. Open `index.html` in a browser — no build step required.

## Deployment

Hosted via **GitHub Pages**:

1. Go to **Settings → Pages** in the repository.
2. Set source to **Deploy from a branch** → `main` / `/ (root)`.
3. The site goes live at `https://your-username.github.io/portfolio/`.
